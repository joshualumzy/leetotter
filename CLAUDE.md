## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (private), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Bug reports

Bugs the user saves from the panel live as local bundles, not issues. To fix them, follow `docs/agents/bug-reports.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, created when needed. See `docs/agents/domain.md`.
